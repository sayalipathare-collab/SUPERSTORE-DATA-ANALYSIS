# 🛒 Superstore Data Analysis

## 📌 Project Overview

This project focuses on analyzing Superstore sales data to understand business performance, customer purchasing patterns, product profitability, and regional sales trends.

The project follows an end-to-end data analytics process, starting with data exploration and cleaning in Python, followed by SQL analysis in PostgreSQL, interactive dashboard development in Power BI, and final reporting and presentation using Gamma.

**Objective:** To turn sales data into meaningful insights that can support better business decisions.

## 📂 Dataset

The Superstore dataset contains information about customer orders, products, sales, profits, discounts, and geographical regions.

Key data fields may include:
- Order Date and Ship Date
- Customer Name and Segment
- Product Category and Sub-Category
- Sales, Quantity, Discount, and Profit
- Region, State, and City

The dataset is used to identify sales patterns, profitable products, and areas where business performance can improve.

## 🔄 Project Workflow

### 1. Data Loading Using Python
Imported the Superstore dataset into Python and examined its structure, columns, data types, and basic statistics.

### 2. Exploratory Data Analysis (EDA)
Analyzed sales, profit, discounts, product categories, customer segments, and regional performance to discover useful patterns.

### 3. Data Cleaning
Prepared the dataset for accurate analysis by checking missing values, identifying duplicates, correcting data types, and addressing inconsistencies where necessary.

### 4. SQL Analysis Using PostgreSQL
Used SQL queries to answer business questions, such as:
- Which product categories generate the highest sales?
- Which regions contribute the most profit?
- Which products perform best?
- How do discounts relate to profitability?
- Which customer segments contribute the most revenue?

### 5. Power BI Dashboard
Designed an interactive dashboard to present important sales and profitability metrics through charts, KPI cards, and filters.

### 6. Project Report
Created a structured report explaining the project objective, dataset, methodology, analysis, major findings, and conclusion.

### 7. Presentation Using Gamma
Prepared a presentation summarizing the project workflow, tools, dashboard visuals, key insights, and business recommendations.

## ▶️ How to Run

### Requirements
- Python 3.x
- Jupyter Notebook
- PostgreSQL with pgAdmin (optional)
- Power BI Desktop

### Steps

1. Download or clone this repository.
2. Open the project folder in VS Code or Jupyter Notebook.
3. Install the Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

4. Load the dataset into the Python notebook and run the analysis cells.
5. Import the cleaned data into PostgreSQL and execute the SQL queries.
6. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
7. Review the final report and Gamma presentation.

*Update dataset paths and database connection settings to match your system.*
